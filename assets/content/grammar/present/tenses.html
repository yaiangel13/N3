Presente continuo de los verbos

Con los verbos estáticos y no de actividad no se utiliza el presente continuo

1. Verbos de sentido
feel -> sentir
hear -> oir
see -> ver
smell -> oler
taste -> sabor

Ej involuntaria: I can see you -> Te veo
Ej voluntaria: I am seeing you later -> Te veré luego
*Si la percepción es voluntaria, se puede usar la forma continua

2. Verbos emotivos
believe -> creer
dislike -> no gustar
like -> gustar
realize -> dar cuenta
recognize -> reconocer
want -> querer
doubt -> dudar
imagine -> imaginar
love -> encantar, amar
remember -> recordar, acordarse
suppose -> suponer
wish -> esperar
hate -> odiar
know -> saber, conocer
prefer -> preferir
think -> creer
understand -> entender, comprender
Ej: I don't believe you! -> ¡No te creo!

3. Verbos de estado o verbos abstractos
be -> ser, estar
cost -> costar
exist -> existir
seem -> parecer
need -> necesitar
care -> importar
contain -> contener
Ej: She is ill -> Ella está enferma

4. Verbos de posesión
belong -> pertenecer
own -> poseer
have -> tener
possess -> poseer
Ej: That belongs to me -> Eso me pertenece

5. Verbos de comunicación
agree -> acordar
astonish -> asombrar
deny -> negar
disagree -> no estar de acuerdo
impress -> impresionar
mean -> significar
please -> agradar
promise -> prometer
satisfy -> satisfacer
surprise -> sorprender
Ej: I disagree -> Yo no estoy de acuerdo
